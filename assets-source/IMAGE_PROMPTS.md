# GenXYZ Lab image-generation prompts

Generate these as standalone artwork—not website screenshots—and export them as optimized WebP files into this directory. The hero is now a responsive HTML/CSS terminal grid, so it does not require generated artwork.

Recommended export target: 200–350 KB per image, sRGB, no embedded text.

## `feature-lab.webp`

Design an isometric premium 3D educational coding laboratory as a standalone visual asset: a sleek floating Android-inspired slate surrounded by modular objects representing a textbook, abstract code brackets, terminal-window geometry, compiler blocks, connected project files, and a refined certificate medallion. Arrange the objects in a clean orbital system communicating the journey from learning to coding to achievement. Dark graphite and midnight-blue materials, frosted glass, subtle cyan data light, violet shadows, warm amber success glow, realistic soft-contact shadows, cinematic studio lighting, restrained bloom, architectural precision, luxurious modern SaaS visual language, highly detailed yet uncluttered. Three-quarter view, balanced negative space, 4:3, 2400×1800. No humans, brand logos, screenshots, readable typography, watermark, or excessive cyberpunk neon.

## `community-constellation.webp`

Create a sophisticated abstract 3D community constellation for an education and developer platform. Form a flowing network of translucent conversation bubbles, small reaction-shaped light particles, bug-report nodes, and connected learning orbs surrounding a warm central scholar light. The scene should communicate constructive feedback, collaboration, trust, and independent development—not social-media hype. Deep ink background, glass and brushed-metal materials, sparse cyan and violet illumination, subtle golden warmth around the center, fine volumetric beams, controlled depth of field, elegant asymmetry, premium editorial technology aesthetic, generous negative space, wide panoramic 21:9 composition, 3200×1370. Standalone background artwork only. No text, numbers, logos, faces, screenshots, watermark, recognizable social-network marks, or noisy neon effects.
