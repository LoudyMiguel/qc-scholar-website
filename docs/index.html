GenXYZ Lab documentation

Official setup and user guide for the GenXYZ Lab Android and Windows application. Learn how to install the app, configure local compilers, use offline courses, open templates, manage project files, and work with the AI and machine-learning studios.

Android setup

Install the official ARM64 APK on Android 8 or newer. Install the current F-Droid version of Termux when you want local compilers, terminals, development servers, or framework toolchains.

Windows setup

Extract the complete Windows x64 ZIP before launching GenXYZ Lab. Keep the executable, libraries, and data folders together, then use Compiler Manager to detect development tools available on PATH.

Features

Explore 70 offline courses, 129 working templates, Code Practice, AI Playground, Dataset Studio, Training Studio, File Explorer, API and database tools, ready-made vision projects, and 13 offline academic solvers.
