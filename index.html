GenXYZ Lab · Free for Android and Windows

Learn coding, build real projects, and experiment with AI and machine learning.

GenXYZ Lab is a free, offline-first learning and creation studio for Android phones and Windows PCs. It combines structured programming courses with practical editors, project templates, developer tools, academic solvers, and open-source games.

One workspace for learning and building

Work through 70 offline courses, practise ten programming-language workflows, and start projects from 129 working templates. Code Practice includes project files, local toolchains, code folding, indentation guides, run consoles, terminals, previews, and compiler setup guidance.

AI, machine learning, datasets, and training

AI Playground creates real machine-learning starter projects. Dataset Studio prepares classification, object-detection, and tabular datasets with labels, train-validation-test splits, and health checks. Training Studio configures and monitors supported local training jobs on Windows, while AI & Vision Projects provides ready-made computer-vision and interactive ML experiences.

Available platforms

Download the official ARM64 APK for Android 8 or newer, or the complete Windows x64 ZIP for Windows 10 and Windows 11. The app is free and does not require a subscription. Network-dependent catalogs and AI providers are optional; downloaded learning material and local tools remain usable offline.
