Website privacy

Effective 9 October 2026

This page describes data handled by the GenXYZ Lab website. It does not replace the privacy information shipped with the application itself.

Anonymous community identity

Firebase Anonymous Authentication creates a random account identifier in your browser so reactions can be toggled and writes can be protected by database rules. GenXYZ Lab does not ask for a social login on this page.

Public comments and reactions

Comments are sent to the site's own server, which checks them and publishes them; see Abuse protection for the limits it applies. Your chosen display name and comment are public. Public comment records do not contain your Firebase author identifier. Reaction membership is stored under random anonymous Firebase identifiers so each account can manage its own vote. Those pseudonymous keys are technically readable with the public reaction data, although the interface displays only totals.

Bug reports

Bug reports are not shown in the public feed. They can be read at their exact database path by the submitting anonymous account and by site administrators. A name, contact method, and device are optional; the description, category, app version, creation time, and report status are stored. Never include passwords, API keys, private source code, or other secrets.

Download counter

When you start a download, the site's server adds one to a global counter and to a counter for the platform you chose (Android or Windows). Both are plain totals; neither is linked to your anonymous identifier, and no device fingerprint is stored. They measure recorded link clicks, not completed downloads or installations, and the server counts a limited number of clicks per network address each day. Cloudflare may separately process normal request logs when serving the site, and GitHub processes the release-file request.

Download map

To draw the public download map, Cloudflare provides the download request's approximate latitude and longitude, derived from your network address, to the site's server. The server immediately rounds each coordinate to the nearest 0.25 degrees (an area roughly 25 kilometres across). Firebase stores only that rounded location and its aggregate download counts per platform. The map record does not include an IP address, precise location, timestamp, device identifier, or Firebase account identifier. Locations recorded before 7 October 2026 were rounded to 5 degrees and remain at that coarser precision.

When you scroll to the map, your browser loads map images directly from the OpenStreetMap Foundation's tile servers. Like any web request, this shares your IP address and browser details with the OpenStreetMap Foundation, under its own privacy policy.

Your browser's reported platform is read once in your own browser so the download button can lead with the build you most likely want. That reading is never transmitted or stored.

Abuse protection

To stop automated spam, the site's server limits how often one network address can post comments and record downloads. For each such request it keeps a keyed hash of your IP address, which cannot be turned back into the address without a secret key, together with a count and the time of your last request. These records are deleted after two days.

If a request from your address breaks a limit, is spam, or comes from a blocked address, the server records the IP address itself, its approximate country, the name and number of the network it belongs to, your browser's user-agent string, and the time and reason. These records are kept for up to 30 days. Only the site operator can read them, and they are used only to detect and block abuse. An address that keeps breaking the limits is blocked for 24 hours. Cloudflare's request logs may show the same details for a short time.

Site analytics

The site uses Cloudflare Web Analytics to count page views and visits and to measure how quickly pages load and respond. A small script from Cloudflare reports to Cloudflare when a page opens and again when you leave or hide it. The reports contain the page address and the referring page with query strings and fragments removed, your browser and operating system names with their major versions, page-load and responsiveness timings, and a random identifier for that single page load. Like any web request, they also reach Cloudflare with your IP address and browser details, from which Cloudflare derives an approximate country. GenXYZ Lab sees only aggregate reports, such as page views by page, referrer, country, and browser. The script sets no cookies and stores nothing in your browser, and Cloudflare states that Web Analytics does not fingerprint visitors. Cloudflare's own handling of request data is described in Cloudflare's privacy policy.

Local storage and retention

Your light or dark theme choice, the display-name convenience field, and the Firebase anonymous session may persist in your browser; site analytics stores nothing there. You can clear site data in browser settings. Public comments remain until moderated. Bug reports are retained while they are being reviewed and are deleted by the operator when no longer needed; the client does not perform automated retention.

Service providers and requests

Firebase processes authentication and database data; Cloudflare hosts the page, provides site analytics, processes approximate location at the edge, and runs the server that applies the abuse limits; the OpenStreetMap Foundation serves the map images; GitHub hosts the public release files. To request correction or deletion, submit a bug report with category Other, include a way to contact you, and identify the relevant content. Because comments do not expose an owner ID, enough detail is needed to locate the item.
