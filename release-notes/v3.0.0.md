# GenXYZ Lab v3.0.0

GenXYZ Lab 3.0 expands the learning studio into a practical AI and machine-learning workspace while improving the core coding experience.

## What is new

- Create real machine-learning starter projects in AI Playground.
- Open ready-made AI, computer-vision, AR, and interactive ML projects.
- Prepare classification, object-detection, and tabular data in Dataset Studio, including labels, dataset splits, and health checks.
- Configure, preflight, run, monitor, and stop local training jobs in Training Studio on Windows.
- Find specialized workspaces through the searchable Tools page, including File Explorer, APIs, databases, developer agents, and 13 offline academic solvers.
- Browse and inspect 129 templates through the redesigned gallery, details, previews, readiness signals, and project-placement flow.
- Navigate larger files with code folding and indentation guides in the enhanced editor.
- Read inputs and results more clearly in the improved project and academic runners.

## Included downloads

- `GenXYZ-Lab.apk` — Android ARM64 release.
- `GenXYZ-Lab-Windows.zip` — complete Windows x64 application folder. Extract the ZIP before launching.
- `SHA256SUMS.txt` — SHA-256 checksums for both downloads.

Keep the complete extracted Windows folder together. Android users updating an existing official installation should install the APK over the current app so local data remains available.
